# 国际象棋 AI 辅助分析小程序 · 生成需求描述（供 WorkBuddy 小程序生成流程）

> 用途：在 WorkBuddy「代码开发 → 小程序」或对话中描述「微信小程序」需求时，直接粘贴本文件内容，即可生成架构一致的小程序，并在对话右侧预览区出现「微信小程序」产物卡片。

## 一句话目标
做一个**微信原生小程序**：用户粘贴国际象棋 FEN 串初始化棋盘，拖动棋子对弈，调用云端 Stockfish 引擎给出三条最佳路线分析。

## 核心功能（首版 MVP）
1. **FEN 初始化**：粘贴 FEN 输入框 +「载入」按钮，初始化棋面（首版不做截图 OCR）。
2. **棋盘渲染**：Canvas 自绘 8×8 棋盘 + Unicode 棋子字形（后续可换图片素材），DPR 适配。
3. **拖拽走子**：手指拖动棋子，合法落点高亮圆点，非法落点弹回；支持自由模拟双方（拖动对方棋子自动翻转行棋方）；兵升变默认升后（Q）。
4. **历史控制**：后退 / 前进 / 重置；SAN 记法走子记录。
5. **终局判断**：将杀、逼和、子力不足、将军的状态提示。
6. **云端 AI 分析**：云函数接收 FEN，返回 MultiPV=3 三条路线（最佳 / 次佳 / 第三）+ 分数（cp 换算为 +1.20 / -0.80，将杀标注）；结果面板展示；走子后自动触发分析。

## 技术与架构偏好（重要，确保与现有设计一致）
- **路线 B**：原生 Canvas 自绘棋盘 + **微信云开发**跑 Stockfish，**不要用 web-view**（个人主体小程序不支持、需备案域名）。
- 规则校验用 **chess.js**（逻辑层，无 DOM 依赖）。
- 棋盘、棋子、合法点高亮、拖拽浮层全部 Canvas 自绘。
- 云函数 `analyze`：入参 `{ fen, depth, multiPV }`，出参 `{ lines:[{ uci, san, scoreCp, scoreMate, pv }], terminal? }`。
- 真引擎接入前，云函数可先用基于合法走法的伪分（MOCK）兜底，保证前端可联调。
- 状态管理页面内轻量自管，MVP 不引入第三方状态库。
- **二期再做人脸/截图 OCR**（截图→裁剪→8×8 切片→模板匹配→FEN），本期不做。

## 已有参考实现（可复用其逻辑与界面结构）
沙箱内已有完整原生小程序源码，结构如下，可直接作为生成参考：
- `pages/analyze/`：分析页（FEN 输入 + Canvas 棋盘 + AI 分析面板 + 走子记录）
- `utils/game.js`：棋局状态（载入 / 落点 / 走子 / 悔棋重做 / 终局判断，纯逻辑可单测）
- `utils/board-render.js`：Canvas 渲染器（初始化 + 绘制棋盘/棋子/高亮/拖拽浮层）
- `utils/geometry.js`：棋格名⇄像素坐标换算、touch 取点
- `utils/ai-client.js`：云函数调用封装 + 分数格式化
- `cloudfunctions/analyze/`：云函数（真实 Stockfish 接入点 + MOCK 兜底）

## 验收标准
- 粘贴任一合法 FEN 能在 1 秒内正确渲染棋盘；
- 可拖动棋子对弈、悔棋、终局判断正确；
- 点「AI 分析」能返回并展示三条路线与分数。
