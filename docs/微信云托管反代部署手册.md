# 微信云托管反代部署手册（B1：引擎后端迁微信云）

> 适用场景：真机预览 / 体验版 / 正式发布时，小程序需要**稳定、已备案、过合法域名校验**的引擎后端。
> 形态：**微信云托管只做反向代理出海**，Stockfish 引擎仍跑在外部（chess-api.com 起步，后续切香港服务器）。
> 配套决策：见 `自建引擎服务部署方案.md` §6「路线 B」、`远端引擎接入方案-chess-api.md` §3「路径 B」。
> 起草日期：2026-10-15

---

## 0. 为什么是「云托管反代」而不是「容器直跑引擎」

| 维度 | B1 云托管反代（本手册） | B2 容器直跑引擎 |
|---|---|---|
| 真机可用 | ✅ 云托管域名已备案 | ✅ 同样可用 |
| 合规 | ✅ 免备案免域名 | ✅ 同样合规 |
| 成本 | ≈22 元/月（0.25 核反代层常驻） | 常驻容器（Stockfish 进程池不能缩到 0，更贵） |
| 引擎算力 | 仍跑外部 16 核满血 Stockfish | 受云托管规格限制 |
| 工作量 | 一个轻量反代容器 + 改 baseURL | 补 Dockerfile + 打包 Stockfish 二进制 + 处理冷启动 |

> 关键事实：`ai-chess-server` 的 Stockfish 是**原生二进制**（`child_process.spawn` 常驻子进程），B2 必须把二进制打进镜像，且承受常驻成本。本项目已有香港 16 核闲置机，故选 B1。

---

## 1. 架构（一句话）

```
小程序（真机/模拟器）
   │  https:// / wss://   ── 云托管已备案域名
   ▼
微信云托管反代容器（Nginx，监听 80，外层终止 TLS）
   │  http://   ── 内部转发
   ▼
上游：chess-api.com（起步）  ⇄  香港 112.121.168.204:8787（后续切换，仅改这里）
```

- 小程序端只改 `baseURL` 指向云托管域名；**上游切换只在反代层改，小程序零改动**。
- 借鉴 `云服务接入经验总结.md` §2.4 方法论：**测试全绿 ≠ 云可用，必须真实探针验证数据面**；改完指向后**核对反代后端实际指向**（别指错成旧上游）。

## 2. 前置确认（务必先过）

- [ ] 微信云开发（CloudBase）环境**已开通**，且本项目已关联该环境
- [x] **容器出网（2026-10-15 已核实 ✅）**：微信云托管服务实例的**公网出向流量默认通过平台默认出口访问公网**（《公网出访》官方文档，https://docs.cloudbase.net/run/deploy/networking/egress），即新建服务默认即能访问 chess-api.com / 香港 IP，**无需额外配 NAT**。少数 `stand_alone_cluster`（独立集群）环境控制台无「公网访问」开关、API `PublicNetStatus=ENABLE` 写不生效，属例外——若踩中需改走 VPC + NAT 网关。出口 IP **不固定**（动态），但本项目上游（chess-api.com 与自有香港机）均不要求白名单，不阻塞 B1。仍建议 Step 7 在容器内真实 `curl` 出网做最终探针（测试全绿 ≠ 云可用）。
- [ ] 上游选定：起步用 **chess-api.com**（无需香港部署）；若香港机已部署 `ai-chess-server` 则直接用香港

## 3. 实操步骤

### Step 1 — 建云托管服务
微信开发者工具 → 云开发 → 云托管 → 新建服务（如 `chess-engine-proxy`），部署方式选「容器」。

### Step 2 — 准备反代容器（Nginx）
新建一个**独立目录**（不属于小程序项目），放这两个文件：

**`Dockerfile`**
```dockerfile
FROM nginx:alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

**`nginx.conf`**（把 `UPSTREAM` 换成你的上游）
```nginx
# 起步：proxy_pass https://chess-api.com;
# 后续切香港：proxy_pass http://112.121.168.204:8787;
upstream engine_upstream {
    server chess-api.com:443;
    # server 112.121.168.204:8787;   # 切香港时启用这行，注释掉上面那行
}

server {
    listen 80;
    location /v1 {
        proxy_pass http://engine_upstream;
        proxy_http_version 1.1;
        # WSS 必需：否则 MultiPV 三线(WebSocket)拿不到
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 120s;   # Stockfish 深度分析可能久，调大
        proxy_send_timeout 120s;
    }
    location /healthz {
        proxy_pass http://engine_upstream;
    }
}
```
> 云托管在外层终止 TLS，容器内只需 HTTP；小程序用 `https://` / `wss://` 访问云托管域名，nginx 内部转发 `http://`。

### Step 3 — 构建并部署镜像
- **方式 A**：本地 `docker build` 后 push 到云托管提供的 TCR 镜像仓库。
- **方式 B**：把 `Dockerfile` + `nginx.conf` 推到 git 仓库，云托管关联「代码仓库自动构建」。
- 部署配置：**监听端口 80**；**最小副本数 = 1**（避免冷启动 20~40s，文档明确建议）；资源 0.25 核即可。

### Step 4 — 拿域名
部署成功后云托管分配 `https://<svc>-<env>.apigw.tencentcs.com`（**已备案**）。记下，下称 `CLOUD_DOMAIN`。

### Step 5 — 小程序侧改 baseURL（你来执行，本手册不碰代码）
打开 `E:\WorkBuddy\ai-chess-wxapp\utils\remote-engine.js`，把 `DEFAULT_ENDPOINT`（或 `configure()` 的 endpoint）改为 `CLOUD_DOMAIN`；WS 版 socket URL 同步改。文档强调「契约不变，只改 baseURL」。
> 提示：可先用开发者工具「编译时条件编译 / 本地临时常量」验证，避免误提交；确认无误再固化。

### Step 6 — 小程序后台加白合法域名
微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名：
- **request 合法域名**：加 `https://CLOUD_DOMAIN`
- **socket 合法域名**：加 `wss://CLOUD_DOMAIN`
真机**必须**；模拟器可临时勾「不校验合法域名」跳过。

### Step 7 — 真实探针验证（关键）
1. 先 `curl` 验证反代通：
```bash
curl -X POST https://CLOUD_DOMAIN/v1 \
  -d '{"fen":"r1bqkb1r/pppp1ppp/2n2n2/4p3/2B1P3/5N2/PPPP1PPP/RNBQK2R w KQkq - 4 4","depth":12,"maxThinkingTime":100,"variants":3}'
```
2. **真机**打开小程序跑三线分析——不能只靠 `remote-engine.test.js` 的 mock。
3. 核对反代后端实际指向（响应里的引擎版本/来源），别指错成旧上游。

### Step 8 — 切到香港（可选，后续）
香港 `ai-chess-server` 部署好并 `listen 0.0.0.0:8787` 后，只改 `nginx.conf` 的 `upstream` 启用香港行、注释 chess-api.com 行，重新部署容器，**小程序端不变**。

## 4. 坑位清单

- **冷启动**：最小副本留 1，否则每次 20~40s。
- **WSS**：nginx 必须配 `Upgrade`/`Connection`，否则三线（WS）失败。
- **容器出网（已核实 ✅）**：云托管**默认即有公网出口**，容器能直连 chess-api.com / 香港 IP，B1 出网前提默认成立，无需配 NAT。仅少数 `stand_alone_cluster` 独立集群环境无平台出口开关（需走 VPC+NAT），且出口 IP 动态不固定（本项目上游无白名单要求，不构成阻塞）。
- **成本**：≈22 元/月（0.25 核常驻）。
- **隐私**：引擎只收 FEN、不碰隐私接口，无需隐私清单（区别于 LLM 点评）。
- **香港机安全**（若切香港）：先按 `自建引擎服务部署方案 §1.1` 收口防火墙（只留 22/80/443），别把 27017/9000 暴露公网。
